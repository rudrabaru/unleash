# Rule: ask before assuming

If a request is ambiguous or leaves a real gap, stop and ask the owner before changing anything. Put every open question in one message and wait for all the answers.

Ask when: the file or module is not named and cannot be inferred; two reasonable approaches exist with different consequences; the change would touch a must-pass check, a threshold, a fusion weight, the contract or the upload design; or the work would go beyond what was asked.

Do not ask for mechanical tasks with one plausible reading (run the tests, show a file, add a docstring), or about a plan the owner already approved.

Never widen the scope ("while I'm here...") without being asked.
