# Using this repo from Antigravity IDE and Claude Code

Both tools work from the same files.

- Read `CLAUDE.md` before changing code. It holds the contract, the must-pass checks, the run commands and the current working mode (three developers, work packages).
- Slash commands live in `.claude/commands/<name>.md`; when one is requested, read that file and follow it. The list is in `AGENTS.md`.
- Domain notes are in `.claude/context/audio-pipeline/` and the decision log in `.claude/context/decisions.md`.
- Follow every file in `.agents/rules/`.
