# Unleash — Team Decision Log

One line of truth per team decision, in git, so all three developers and every Claude session see the same thing. `docs/` is gitignored and can drift between machines; this file cannot.

**Rule:** a decision that changes a hard gate, a threshold, a shared schema, the fusion weights or the upload design (CLAUDE.md Section G) is recorded here in the same commit that implements it. Add new entries at the bottom of the table; never rewrite an old one — mark it `Superseded by D-xx` instead.

**Status values:** `Agreed` (team signed off) · `Agreed, value pending evidence` (direction agreed, the exact number is set from recorded measurements) · `Done` · `Superseded`.

## Open items still needing a team call

- Final value of the Stage 2 confidence floor (D-04): stays 0.5 until ≥ 10 genuine human takes from ≥ 3 speakers exist; candidate 0.3.
- **Vocabulary-dump attack (found while running D-23):** the matcher does not penalise extra words, so an attacker who reads many vocabulary words in the 15 s window covers the challenge by chance — P(≥ 4 of 5 challenge words covered) ≈ 0.8% at 30 distinct words, 2.6% at 40, 11.8% at 60 (hypergeometric, 136-word pool). Independent of the recognizer. A cap on recognized words (e.g. reject when far more words are heard than expected) would be a hard-gate change (Section G); needs a team decision.
- Lip-series per-sample timestamps (B4): this changes the interface in CLAUDE.md §E and `av-alignment-interface.md`; both must change in the same commit.
